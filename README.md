## Overview

This repository acts as a structured collection of my relational database coursework and practical exercises. It is organized into two primary sections:

1. **Core Concepts (`/concepts/`):** Annotated SQL query scripts demonstrating database design, CRUD operations, and advanced joins.
2. **Practical Exercises (`/exercises/`):** Homework assignments, schema designs, and complex data retrieval challenges.
